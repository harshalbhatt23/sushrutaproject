====== Suśruta Project manuscript transcriptions of MS London IOLR Taylor 1842 (Eggeling 2646). ======


This is the repository for the manuscript transcriptions from MS IOLR Taylor 1842 (Eggeling 2646)
created as part of the
[[http://sushrutaproject.github.io|sushrutaproject.github.io]], q.v. for the full details.

Although Eggeling identified this MS as supporting the Suśrutapāṭhaśuddhi of Candraṭa, in fact it does not.  It supports the commentary of Ḍalhaṇa.

This repository is currently maintained by Dominik Wujastyk.
